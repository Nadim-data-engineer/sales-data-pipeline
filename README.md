# Sales Data Pipeline

## Project Overview
This project demonstrates a basic sales data processing pipeline
using Python, Pandas, SQL, and ETL concepts.

## Technologies Used
- Python
- Pandas
- SQL
- CSV

## Project Workflow
1. Extract sales data using Python.
2. Calculate total sales for each order.
3. Remove duplicate records.
4. Export processed data to a CSV file.
5. Use SQL queries to analyze sales revenue.

## Project Files
- sales_etl.py - Python ETL script.
- sales_analysis.sql - SQL queries for sales analysis.
- README.md - Project documentation.

## How to Run
1. Install Python.
2. Install Pandas:
   pip install pandas
3. Run the Python script:
   python sales_etl.py

## Expected Output
The script calculates total sales and saves the processed
data to processed_sales.csv.
